# TEST_PLAN — 测试计划

> `dp-workflow` · 测试层 · owner `dpwf-dev`

> 测试用例**必须逐条反向映射回 `docs/dp-workflow/requirements/SPEC.md` 的验收标准**（AC）。每条 AC 至少一个用例，且用例必须**真测该 AC 声称的行为**，不能用不相关的替身顶替。
