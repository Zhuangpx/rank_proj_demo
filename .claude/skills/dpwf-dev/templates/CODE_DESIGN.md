# CODE_DESIGN — 代码级设计

> `dp-workflow` · 实现层 · owner `dpwf-dev`

> 定位：架构设计（DESIGN.md）→ 代码 之间的桥梁。DESIGN.md 回答「要什么、为什么」（技术选型/架构/数据模型/接口/里程碑），本文件回答「代码怎么组织、关键链路怎么走」。
